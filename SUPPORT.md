# Support

Use [GitHub Discussions](https://github.com/filinodz/ForeverCMS/discussions) for
installation and configuration questions. Use
[GitHub Issues](https://github.com/filinodz/ForeverCMS/issues) for reproducible bugs
and feature proposals.

When asking for help, include the ForeverCMS version, Windows/PHP version, the
affected page and sanitized logs. Never post passwords, private IP addresses,
account e-mails, session cookies or database dumps.
