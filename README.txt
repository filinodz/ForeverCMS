FOREVER CMS - STANDALONE OR REPACK
=================================

Read README.md in this folder for the complete English installation guide,
privacy notes, configuration, credits and troubleshooting.

Forever adaptation, launcher integration and visual design: FilinoDZ.
Based on the open-source SahtoutCMS: https://github.com/SahtoutDev/SahtoutCMS

Standalone quick start (no launcher required):
  1. Start your existing ForeverCore MySQL server.
  2. Run Install-Standalone.bat and enter your database/realm settings.
  3. Run Start-CMS.bat for a local preview at http://127.0.0.1:8080.
  4. For public hosting, follow docs/STANDALONE.md and use a production PHP host.

The website database is separate. Existing game accounts and characters are
not reset. A compatible ForeverCore installation is required; this is not a
game-server installer. Optional repack integration is documented in README.md.

Discord: Admin Panel > Settings > General. Set the invitation URL and, for a
guaranteed widget, the numeric Discord server ID.
